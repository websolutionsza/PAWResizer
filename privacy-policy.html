Privacy Policy

Your images never leave your browser

PWA Resizer is built with a privacy-first architecture. Every pixel you upload is processed locally on your device using the HTML5 Canvas API. There is no server-side upload, no cloud storage, and no tracking of your files.

100% Client-Side Processing

When you select an image, it is read into your browser's memory using the FileReader API and drawn onto an HTML5 Canvas element. Resizing, masking, background compositing, and format conversion all happen in JavaScript on your device. The resized output is offered back to you as a direct download. At no point is your image data transmitted over the network.

What we collect

PWA Resizer does not require an account, login, or any personal information to use. The application does not set any tracking cookies, analytics pixels, or fingerprinting scripts. We do not collect your name, email address, IP address, location, or device identifiers.

The only data stored on your device

  • Theme preference: Your light or dark mode choice is saved in localStorage under the key pwa-theme so the app remembers your preference next visit. This never leaves your browser.

How image processing works

Here is exactly what happens when you upload an image to PWA Resizer, step by step. Understanding this flow should give you full confidence that your files remain private.

Step What happens Leaves device?
1. File selection You pick a file via the system file picker or drag it onto the upload zone. No
2. Read into memory The FileReader API reads the file bytes into a JavaScript data URL in your browser's memory. No
3. Load into Image The data URL is assigned to an Image element so the browser decodes it into a bitmap. No
4. Draw to Canvas The bitmap is drawn onto an HTML5 Canvas at your chosen dimensions with masks, padding, and backgrounds applied. No
5. Export to Blob canvas.toBlob() encodes the result as a PNG or JPEG binary blob in memory. No
6. Offer download A temporary object URL is created and triggered as a download. The blob is revoked shortly after. No

SVG files follow the same path - they are parsed as text, their intrinsic dimensions are read from the viewBox or width and height attributes, and they are rasterized onto the canvas at your chosen output size. The SVG source text never leaves your browser.

Third-party resources

PWA Resizer loads a small number of external resources to function. None of these resources receive your image data. They are loaded only as static assets.

  • Google Fonts (Inter): The Inter typeface is loaded from fonts.googleapis.com so the interface renders consistently across devices. No image data is shared with Google.
  • JSZip library: Loaded from cdnjs.cloudflare.com to enable ZIP package generation. The library runs entirely in your browser and does not transmit file contents anywhere.
  • Logo image: The PWA Resizer logo is fetched from GitHub raw content. This is a static asset request and carries no user data.

If you prefer to avoid even these static external requests, you can self-host the application by downloading the source and replacing the CDN URLs with local copies.

LocalStorage and cookies

The application uses a single localStorage key to remember your theme preference. This data is stored only in your browser and is never sent to any server. You can clear it at any time through your browser's site data settings.

PWA Resizer does not set any cookies - not session cookies, not authentication cookies, and not tracking cookies. There are no advertising or analytics scripts embedded in the application.

Your rights

Because PWA Resizer does not collect, store, or transmit any personal data or image content, there is no personal data repository to access, correct, or delete. Your images exist only in your browser's memory for the duration of your session and are discarded when you close the tab or navigate away.

The theme preference stored in localStorage is fully under your control. You can remove it through your browser settings or by clearing site data. No request to us is required.
