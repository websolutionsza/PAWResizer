User Guide

How to use PAW Resizer

A clear, step-by-step walkthrough covering image uploads, maskable safe-zones, padding and backgrounds, and exporting single files or full ZIP packages - all processed privately in your browser.

1 Upload 2 Safe-Zone 3 Padding 4 Export
01

Uploading Images

PAW Resizer accepts PNG, JPEG, WEBP, and SVG files. Everything you upload stays on your device - the image is read into memory and drawn onto an HTML5 Canvas entirely in your browser. No file is ever transmitted to a server.

Single file upload

Click anywhere inside the dashed upload zone, or tap it on mobile. Your device's file picker will open. Select one image and it will load into the preview pane within a second. The original dimensions, file size, and filename are displayed beneath the preview so you always know what you are working with.

Multi-file drag and drop

You can drag multiple image files from your desktop directly onto the upload zone, or select several files in the file picker by holding Ctrl (Windows) or Cmd (macOS). When more than one file is loaded, a thumbnail strip appears below the upload zone. Each thumbnail is clickable to switch the active image, and a small remove button sits in the top-right corner of each thumbnail so you can quickly drop an unwanted file from the batch.

  • Click a thumbnail to make that image the active one for editing.
  • Remove button (the small "x") deletes that image from the batch without affecting the others.
  • Batch counter in the card header shows how many images are loaded.
SVG files are rasterized cleanly at whatever dimension you choose. If your SVG has no intrinsic size, PAW Resizer reads its viewBox and uses that as the source dimensions, defaulting to 512x512 if neither is present.

Cropping before resizing

The crop button in the Preview card header opens a cropping overlay. Drag the blue selection box or its corner handles to frame the area you want to keep, then apply. The cropped result becomes the new active image and the original is replaced in the batch. This is useful when your source image has whitespace or borders you want to remove before generating icons.

02

Using the Maskable Safe-Zone Toggle

Android adaptive icons (also called "maskable" icons) can be cropped by the device launcher into shapes like circles, squircles, rounded squares, or teardrops. To survive every possible mask, your icon's important content must sit inside a central safe zone - a circle with a diameter equal to 80% of the icon's full size.

Turning the safe-zone on

In the Asset Presets card, flip the Show maskable safe-zone toggle. A dashed white circle appears over your preview, marking the boundary inside which all critical visual content must remain. Anything outside the circle may be clipped by an aggressive launcher mask, so keep logos, text, and key shapes within it.

Pairing with the Android preset

The Android quick preset automatically sets the dimensions to 512x512 and switches the safe-zone toggle on. This is the recommended starting point for generating maskable icons. Use the safe-zone circle as a guide while you adjust padding (see step 3) so your logo sits comfortably centered with breathing room on all sides.

The safe-zone overlay is a preview guide only - it is never burned into the exported file. Your downloaded icon will not contain the dashed circle.

When to use it

  • Maskable / adaptive icons (Android): Always enable. Standard 192x192 and 512x512 maskable entries in your manifest should be designed with this zone in mind.
  • Apple touch icons (iOS): Not required. iOS applies its own rounded-square mask, so you can fill the full canvas. The iOS preset turns the safe-zone off automatically.
  • Favicons: Not required. Browsers display favicons at small sizes, so use the full frame and keep the design simple.
03

Adjusting Padding and Backgrounds

The Canvas Background card lets you place your image on a colored or transparent backdrop with adjustable padding. This is essential for maskable icons, where you typically want your logo sitting on a solid background color with padding around it so the launcher mask never cuts into the artwork.

Enabling the background

Toggle Add background padding on. A set of options appears: background type, color or gradient stops, gradient angle, and a padding percentage slider. When enabled, your source image is scaled to fit within the inner area (canvas size minus padding on all sides) while preserving its aspect ratio, then centered on the background fill.

Background types

  • Solid: A single flat color. Pick the color with the swatch. Ideal for maskable icons that need a consistent brand background.
  • Gradient: A two-stop linear gradient. Set the start and end colors, then adjust the angle from 0 to 360 degrees. Great for splash screens or decorative icons.
  • Transparent: No fill is drawn - the canvas stays transparent. Use this for PNG favicons or icons that should let the underlying surface show through. JPEG does not support transparency, so switch to PNG when using this mode.

Padding percentage

The padding slider runs from 0% to 50%. At 10% (the default for the Android preset), your image is inset by 10% of the canvas size on every side, leaving a frame of background around it. Higher values give more breathing room; lower values fill more of the canvas. For maskable icons, 10% padding combined with the safe-zone overlay typically keeps your logo well inside the protected area.

Turn on the safe-zone overlay while adjusting padding. If your logo fits entirely inside the dashed circle, it will survive every Android launcher mask shape.

Edges and shape masks

Separately, the Edges and Mask card lets you round the output itself with a shape mask - rounded rectangle, circle, squircle, teardrop, or rounded hexagon. You can also add a colored border stroke (inner or outer). These masks are applied to the final canvas, so they work together with background padding. Note that shape masks produce transparency in the corners, so PNG is the recommended output format when a mask is active.

04

Exporting Single Files vs ZIP Packages

PAW Resizer offers two export modes, controlled by the chips in the Batch and Package card: Single File and ZIP Package. Each serves a different stage of your workflow.

Single File export

Choose Single File to export the current image at exactly the dimensions shown in the Resize Dimensions card, using the selected output format (PNG or JPEG). Click Resize and Download and the file downloads immediately with a name like logo-192x192.png. This is the fastest path when you need one specific size - for example, generating a 180x180 apple-touch-icon or a 32x32 favicon.

  • PNG: Lossless, supports transparency. Best for icons, favicons, and maskable assets.
  • JPEG: Lossy with an adjustable quality slider (10-100%). Best for splash screens and photographic content where file size matters more than sharp edges.

After a single-file export, a green result card appears in the preview pane showing the output dimensions, format, and file size, plus a Download Again button in case you need another copy.

ZIP Package export

Switch to ZIP Package to generate a complete PWA icon set in one downloadable archive. The action button changes to Download ZIP Package, and a checklist of bundle contents appears. Tick or untick the categories you need:

  • Android icons: 192x192 and 512x512 maskable PNGs with 10% padding applied, placed in the android/ folder.
  • iOS icons: 180x180 apple-touch-icon plus 120, 152, and 167 variants, and seven common splash-screen ratios, in the ios/ and ios/splash/ folders.
  • Favicon: A multi-size favicon.ico (16, 32, 48) plus individual PNGs, in the favicons/ folder.
  • manifest.json: A ready-to-use web app manifest referencing all generated icons.

The archive also includes standard PWA sizes (16 through 512) in the icons/ folder, Microsoft tile graphics in microsoft-tiles/, and a browserconfig.xml for Windows tiles. Drop the unzipped folders into your project root and link the manifest from your HTML.

ZIP generation processes many sizes in sequence, so it can take a few seconds on large source images. Keep the tab focused during generation - some browsers throttle background work.

HTML Metadata Snippet

Once you have your files, scroll to the HTML Metadata Snippet card on the main page. It auto-generates a ready-to-paste block of manifest and apple-touch-icon link tags based on your current dimensions and settings. Click Copy and drop it into the <head> of your HTML document.
